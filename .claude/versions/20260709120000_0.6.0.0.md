# Versão 0.6.0.0 — Logo e ícones

Data: 2026-07-09

## Objetivo

Trocar o ícone genérico de marca por um logo próprio (relógio com o "f" e as setas), em SVG, PNG e
ICO, adaptando a cor ao tema (dourado no dark, preto no light).

## O que foi feito

- **`public/logo.svg`** — o relógio recriado como vetor (anel, numerais romanos XII/III/VI/IX e o
  "f" com três setas). **Theme-aware num único arquivo**: usa `currentColor` + um `<style>` com
  `@media (prefers-color-scheme)` (dourado `#c8a04a` no dark, preto `#141414` no light). Serve
  também de favicon SVG.
- **`public/logo.png`** (512×512, dourado, fundo transparente) e **`public/favicon.ico`**
  (16/32/48/64). Gerados a partir de uma variante dourada do SVG com `@resvg/resvg-js` +
  `png-to-ico`, instalados com `--no-save` (não entraram no `package.json`); o `favicon.svg` padrão
  do Vite foi removido.
- **`index.html`**: favicon religado (`logo.svg` para navegadores modernos, `favicon.ico` de
  fallback, `logo.png` como apple-touch-icon).
- **`components/Logo.tsx`**: o mesmo desenho como componente React inline, usando `currentColor`.
  Colocado no `AppHeader` no lugar do `ArticleOutlinedIcon`, ao lado do nome. A cor por tema é feita
  com `theme.applyStyles('dark', { color: '#c8a04a' })` sobre um padrão `#141414` (o jeito correto
  com o tema de CSS variables do MUI).

## Observações

- É uma **recriação vetorial feita à mão** a partir da imagem enviada (não um traço pixel-a-pixel).
  Ficou fiel; se houver o vetor original, dá para substituir para fidelidade perfeita.
- A "versão preta para o light" não precisou de arquivo separado: o `currentColor` resolve isso
  tanto no componente (via `applyStyles`) quanto no SVG standalone (via `prefers-color-scheme`).

## Verificação (backend real via `dev-login`)

- Logo presente no header (`svg[aria-label="news-feed-client"]`, 30px). Cor computada:
  **`rgb(200,160,74)` (dourado)** no dark; após o toggle, **`rgb(20,20,20)` (preto)** no light.
- `logo.svg` standalone renderiza dourado no dark e preto no light (media query).
- `logo.png` conferido visualmente (numerais e "f" corretos, fundo transparente).
- Build, lint e format verdes; sem erros de console.
