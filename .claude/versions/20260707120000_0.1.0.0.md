# Versão 0.1.0.0 — Arquitetura e padrões técnicos

Data: 2026-07-07

## Objetivo

Fechar a definição de arquitetura e padrões técnicos do cliente (somente documentação, sem código).
Resolve as duas dúvidas em aberto do roadmap.

## O que foi feito

- **Stack finalizada** (em `CLAUDE.md`, editada pelo usuário durante a discussão): resolvidos os
  conflitos iniciais (removidos Next.js e Tailwind) e adicionadas as peças que faltavam —
  TanStack Query, React Hook Form + Zod, react-i18next, date-fns (+ tz), Vitest + React Testing
  Library + Playwright, DOMPurify, ESLint + Prettier. Stack final:
  TypeScript, Vite, React, React Router, React Context + localStorage, React Hook Form, react-i18next,
  Material UI, Axios, TanStack Query, Zod, date-fns, Vitest/RTL/Playwright, DOMPurify, ESLint/Prettier.

- **`rules/architecture.md`** (novo): padrão técnico completo — tipo de app (SPA React+Vite,
  roteamento client-side), fluxo de auth/sessão (Google OAuth via fragment; `access_token` em
  memória no Context, `refresh_token` no `localStorage`, reidratação via `/auth/refresh` no boot),
  gerência de estado (TanStack Query para estado de servidor; Context só para sessão e tema),
  comunicação com a API (instância única do Axios + interceptors de Bearer/refresh-no-401/503,
  um serviço por modelo), variáveis de ambiente do frontend (prefixo `VITE_`, config pública),
  datas (UTC → fuso do usuário com date-fns), i18n (PT/EN; conteúdo da notícia no idioma da API),
  renderização de HTML (DOMPurify) e guard de manutenção (503).

- **`rules/structure.md`**: preenchida a estrutura-alvo de pastas (`src/` com components, contexts,
  hooks, i18n, pages, routes, services/api, theme, types, utils; além de `tests/` e `cmd/`). As
  pastas de código passam a existir de fato a partir da 0.2.0.0.

- **`rules/conventions.md`**: adicionada a nuance de que o `.env` do frontend é configuração pública
  (não cofre de segredos), com prefixo `VITE_`.

- **`ROADMAP.md`**: itens da 0.1.0.0 marcados como concluídos; versão atual subida para 0.1.0.0.
  (O usuário havia movido o tooling `.gitignore`/Prettier/ESLint para a 0.2.0.0, após alerta de
  sequência: essas configs dependem do `package.json`/scaffold do Vite.)

## Decisões-chave

- **SPA com Vite** (sem Next.js): o OAuth do backend devolve tokens no fragment da URL, padrão de SPA.
- **Sessão**: React Context (memória) + `localStorage` (persistência), análogo a Pinia + persistedstate.
- **Estado de servidor no TanStack Query**, deixando o Context enxuto (só sessão e tema).

## Fora de escopo (próximas versões)

- 0.2.0.0: scaffold do npm/React/Vite, `.gitignore`, Prettier/ESLint e um "olá mundo".
- 0.3.0.0+: layout, páginas e testes.
