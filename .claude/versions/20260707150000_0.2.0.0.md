# Versão 0.2.0.0 — Bootstrap do projeto Vite + React + TS

Data: 2026-07-07

## Objetivo

Materializar o projeto: scaffold Vite + React + TypeScript, tooling (gitignore, env,
Prettier/ESLint) e um "olá mundo" com o Vite de pé. Bootstrap enxuto, sem as libs de feature.

## O que foi feito

- **Scaffold** via `create-vite` (template `react-ts`) gerado num diretório temporário e copiado
  para a raiz, preservando `.claude/`, `.git/` e o `README`. Versões (latest no momento):
  React 19.2, Vite 8.1, TypeScript 6.0, `@vitejs/plugin-react` 6.
- **`package.json`**: nome `news-feed-client`, `version` `0.2.0` (ver nota de versionamento abaixo),
  scripts `dev`/`build`/`preview`/`lint`/`lint:fix`/`format`/`format:check`.
- **TypeScript estrito**: adicionado `"strict": true` em `tsconfig.app.json` e `tsconfig.node.json`
  (o template novo não o traz por padrão), atendendo à convenção de código estrito.
- **`.gitignore`**: base do template + bloco de env correto para Vite —
  ignora `.env` e `.env.*`, mantendo apenas `.env.example` versionado.
- **`.env`**: `.env.example` (versionado) e `.env.local` (ignorado) com `VITE_API_URL` (prefixo
  `VITE_` obrigatório para exposição ao cliente). Removidos `PROJECT_NAME`/`PROJECT_VERSION` do env
  (metadados do app vêm do `package.json`, não de env pública).
- **ESLint + Prettier**: `oxlint` (novo padrão do template) removido em favor da stack documentada.
  ESLint 10 flat config (`eslint.config.js`) com `typescript-eslint`, `react-hooks`,
  `react-refresh` e `eslint-config-prettier`. Prettier com `.prettierrc.json` (sem `;`, aspas
  simples, trailing commas, indentação de 4 espaços) e `.prettierignore` (ignora `dist`,
  `node_modules`, lockfile e `.claude`).

## Ambiente

- Node 22.17. npm atualizado para 11.18.0 durante o desenvolvimento (era 9.7.2); `npm install`
  retornou `up to date` — sem impacto em dependências ou lockfile.
- **Olá mundo**: `App.tsx` reduzido a um placeholder (a UI real e i18n chegam na 0.3), demo do
  template removida (`App.css`, `src/assets/*`, `public/icons.svg`), `index.css` reduzido a um reset.

## Verificação

- `npm run build` (tsc estrito + vite build): OK — bundle gerado.
- `npm run lint`: OK — sem erros.
- `npm run format:check`: OK — todos os arquivos no padrão.
- Dev server (`npm run dev`): HTTP 200 em `http://localhost:5173`, título `news-feed-client`,
  entry `main.tsx` referenciado. Olá mundo de pé.

## Notas e pendências para o usuário (git)

- **Versionamento**: o esquema do projeto é 4 partes (`major.minor.patch.docs`), mas o `version`
  do `package.json` precisa ser semver (3 partes). Ficou `0.2.0` (descartado o dígito `docs`).
- **`.env_example` (underscore)**: o HEAD versiona um arquivo `.env_example`; passamos a usar
  `.env.example` (ponto), convenção padrão do Vite (e coberta pelo `!.env.example` no gitignore).
  O antigo `.env_example` deve ser removido do versionamento pelo usuário.
- **`README.md`**: normalizado pelo Prettier (mudança de formatação apenas).

## Gotcha registrado

- `eslint-plugin-react-hooks` v7 moveu os configs flat para `.configs.flat`; usar
  `configs['recommended-latest']` (formato legado, `plugins` como array) quebra no ESLint 10.
  Correto: `reactHooks.configs.flat['recommended-latest']`.
