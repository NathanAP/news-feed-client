# Versão 0.15.0.0 — Tutorial de fluxo (Ajuda + boas-vindas)

Data: 2026-07-16

Segunda fatia do bloco de onboarding replanejado na 0.14. Entrega o tutorial "por cima" de como a
aplicação funciona, com **uma** descrição do fluxo servindo **dois** gatilhos.

## O que foi feito

### 1. `TutorialSteps` — o conteúdo único

`components/tutorial/TutorialSteps.tsx`: um MUI `Stepper` com os três passos (1—2—3), com o conector
padrão (a linha entre os números é justamente a assinatura visual pedida).

- **Overview, não wizard**: todos os passos são renderizados `active` de propósito — a pessoa não
  caminha por eles, ela lê os três de uma vez.
- **Responsivo**: horizontal + `alternativeLabel` no desktop, **vertical** abaixo de `sm` (três
  colunas de texto ficam espremidas no celular), via `useMediaQuery(theme.breakpoints.down('sm'))`.
- **Marca**: os números usam o dourado (`brand.main`), coerente com a identidade registrada no
  `PROJECT.md` ("destaques de onboarding").

### 2. `TutorialDialog` — o invólucro, em duas variantes

`TutorialVariant` (objeto `as const` em `tutorialVariant.ts`, conforme a convenção de enums do
projeto — e em módulo próprio porque um arquivo de componente não pode exportar valores de runtime,
regra `react-refresh/only-export-components`):

- **`Help`**: aberto de propósito pela entrada nova **"Ajuda"** no menu do avatar. Título "Como
  funciona", ação "Fechar".
- **`Welcome`**: automático no primeiro acesso. Título "Bem-vindo ao ChronoFeed", ação "Começar"
  (botão `contained`, por ser o passo adiante).

Ambos renderizam o mesmo `TutorialSteps` — só o enquadramento muda.

### 3. Primeiro acesso

- `hooks/useTutorialSeen.ts`: flag `nfc.tutorialSeen` no `localStorage` (prefixo `nfc.` seguindo o
  `feedOrderStore`). `useState` inicializado por leitura única + `markSeen()` que persiste.
- Montado no **`AppLayout`** (não numa página) para recepcionar a pessoa onde quer que ela caia na
  área autenticada.
- **Limitação consciente**: é **por-dispositivo**. O backend não tem campo para "já viu o tutorial",
  então a mesma pessoa em outro navegador é recepcionada de novo. Mesma natureza da ordenação de
  feeds da 0.11; sincronizar no servidor é upgrade futuro.

### 4. Carregamento

`LazyTutorialDialog` segue o padrão do `LazyFeedFormDialog` (render `null` enquanto fechado). Importa
porque o `AppLayout` é **eager**: sem o wrapper, o `Stepper` entraria no chunk principal. Medido: o
chunk `TutorialDialog` é **14.9 kB** (4.85 kB gzip) e só baixa ao abrir; o principal foi de 471.5 kB
para 475.9 kB (o ícone novo + hook + wrappers).

## Gotcha encontrado e corrigido durante a versão

**`theme.palette.*` "congela" o esquema base quando o tema usa `cssVariables`.** Ao estilizar o
número dentro do círculo dourado, escrevi:

```ts
fill: theme.palette.brand.contrastText // ERRADO
```

A regra emitida foi `fill: rgb(255, 255, 255)` — um literal, e justamente o `contrastText` do
esquema **light**, aplicado também no dark (número branco sobre dourado claro: contraste ruim).
Motivo: com `cssVariables`, `theme.palette.*` devolve o valor resolvido do esquema base, não a
variável. `fill` não é prop de sistema do `sx`, então também não aceita o caminho
`'brand.contrastText'`. Corrigido usando a variável direto:

```ts
fill: 'var(--mui-palette-brand-contrastText)'
```

(`theme.vars.palette...` seria o ideal, mas `theme.vars` é tipado como possivelmente `undefined` e o
projeto proíbe `!`.) É irmão do gotcha do `alpha()` registrado na 0.14. Verificado nos dois temas.

## Verificação

- `npx tsc -b`, `npm run lint`, `prettier` e `npm run build` limpos.
- No navegador (`localhost:5173`, sessão dev):
    - **Boas-vindas**: limpando `nfc.tutorialSeen` e recarregando, o modal aparece com
      "Bem-vindo ao ChronoFeed" + os 3 passos + "Começar". ✓
    - **Persistência**: "Começar" fecha e grava `nfc.tutorialSeen=true`; recarregar **não** reexibe. ✓
    - **Ajuda**: menu do avatar agora é Perfil / Preferências / **Ajuda** / Sair; abre o mesmo
      conteúdo com "Como funciona" + "Fechar", sem tocar na flag. ✓
    - **Marca/contraste** (alternando pelo botão de tema, o caminho real): dark → círculo `#c8a04a`
      com número `#14161b`; light → círculo `#8a6a1f` com número branco. ✓
    - **Responsivo**: a 375 px o stepper monta **vertical**; no desktop, horizontal. ✓ Sem scroll
      horizontal de página.
- **Não verificado**: a reação a um redimensionamento **ao vivo** com o diálogo já aberto — o resize
  do harness não propagou o evento para a página (o `innerWidth` ficou preso). O caminho real (abrir
  o diálogo num dado tamanho) está correto nos dois tamanhos, e `useMediaQuery` é o hook padrão do
  MUI para isso.

## Nota de método

O primeiro teste de tema foi feito forçando `document.documentElement.className` na mão e produziu
uma leitura **falsa** (círculo dourado igual nos dois temas). Alternar pelo botão real do tema — que
re-renderiza via `useColorScheme` — deu o resultado correto. Para conferir cor por tema, usar o
toggle, não a classe na marra.

## Como testar

1. Menu do avatar → **Ajuda**: abre "Como funciona" com os três passos.
2. Para rever as boas-vindas: apagar `nfc.tutorialSeen` no `localStorage` (DevTools → Application) e
   recarregar — o modal "Bem-vindo ao ChronoFeed" aparece. "Começar" fecha e não volta mais.
3. Alternar o tema com o diálogo aberto: os números ficam dourados e legíveis nos dois modos.
4. Estreitar a janela para largura de celular e abrir a Ajuda: os passos empilham.
