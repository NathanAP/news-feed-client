# Versão 0.12.0.0 — Sincronizar client com o novo contrato do backend

Data: 2026-07-09

## Motivação

O backend mudou duas coisas que afetam o client (documentadas em `memory/api-integration.md` e
`memory/endpoints.md`):

1. **Preferências**: `theme` saiu da API (agora client-only) e `language` + `translate_content`
   viraram um único `language_to_translate` anulável. Rota de tradução agora é
   `GET /articles/:id/translate` (idioma-alvo vem do JWT, não da URL).
2. **Conteúdo HTML**: já vem sanitizado (bluemonday) com allowlist incluindo iframes de YouTube/Twitch
   (Instagram vira link; sem `class`/`style`/`id`). O client não precisa re-sanitizar.

## Parte A — Preferências

- `types/preferences.ts`: removido o enum `Theme`; `UserPreferences = { languageToTranslate: Language
| null, aiPersonality }`; DTOs no shape novo (`language_to_translate`, `ai_personality`).
- `UsersService`: mapeamento camel↔snake atualizado.
- **Tema agora é client-only**: deletado `hooks/useThemeSync.ts` e o acoplamento com o backend; o
  `ThemeToggle` voltou a ser puro `setMode` (o MUI persiste o modo em localStorage — `mui-mode`).
- `PreferencesDialog`: removidos o select de tema e o switch de traduzir. Agora tem:
    - **Idioma da interface** (i18next, client-only, aplica **na hora** — fora do form RHF e do backend).
    - **Idioma de tradução** (select com "Desativado" → `null`, + 6 idiomas).
    - **Personalidade da IA**.
- **Idioma da UI movido do menu para as preferências** (`UserMenu` perdeu o switcher PT/EN).
- i18n: `preferences.uiLanguageLabel`, `preferences.languageOptions.off`; removidos
  `preferences.themeLabel`/`themeOptions`/`translateContentLabel` e `menu.language`.

## Parte B — Remover DOMPurify + embeds responsivos

- `ArticleDetailPage`: removido o `DOMPurify.sanitize()`; renderiza `article.content` direto. Box de
  conteúdo ganhou CSS responsivo pro iframe (`& iframe { width: 100%; aspect-ratio: 16/9; height:
auto; border: 0 }`) — sem wrapper, já que o conteúdo não tem `class`/`id`.
- **`dompurify` desinstalado** (dependência morta; provavelmente volta no futuro). Removido da lista
  de stack do `CLAUDE.md`. Efeito colateral: o chunk do `ArticleDetailPage` caiu de ~28 kB para ~2 kB.
- Docs: `PROJECT.md` (rota de tradução e referência de memória corrigidas; a seção de renderização de
  HTML já tinha sido ajustada pelo dono). Nota de config: o `parent` da Twitch é reescrito pela API
  para o host do `CLIENT_URL` — em dev, o client precisa ser servido nesse host pra Twitch reproduzir.

## Correção encontrada na verificação

A sentinela do "Desativado" era `''`, mas o `Select` do MUI trata `value=""` como "sem seleção" e
**não exibia o rótulo** "Desativado" ao reabrir. Trocada por uma sentinela não-vazia (`'off'`).

## Verificação (dev-login, `localhost:5173`, backend novo)

Preferências do dev capturadas e **restauradas** (`language_to_translate=pt`, `ai_personality=mixed`).

- **Preferências**: diálogo carrega o shape novo (Português/Mista), **sem tema e sem switch**. Salvar
  "Desativado" → persiste `null` → reabre mostrando "Desativado" (após o fix). Restaurado para Português.
- **Idioma da interface**: trocar para English traduz o app inteiro **na hora** (i18next → localStorage),
  sem salvar; `UserMenu` não tem mais o switcher. Restaurado para Português.
- **Tema**: toggle vira `light`, persiste `mui-mode` no localStorage, **sem `PUT`** no backend.
- **DOMPurify/embeds**: conteúdo (com `<img>`) renderiza direto (sem regressão); um iframe de teste
  no Box de conteúdo fica **100% de largura, 16:9, sem borda** (`& iframe` aplicado). Não há embed real
  de YouTube/Twitch nos dados de dev, então o embed em si depende de conteúdo que os contenha.
- `npm run build` / `lint` / `format` verdes; sem erros de console.

## Como testar

- Preferências (menu do avatar → Preferências): idioma da interface troca o app na hora; idioma de
  tradução ("Desativado" + idiomas) e personalidade da IA salvam no backend.
- Tema (toggle do header): alterna e persiste só no client.
- Embeds: abrir uma notícia que contenha um vídeo de YouTube/Twitch — o iframe aparece e é responsivo.
